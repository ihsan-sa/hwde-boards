- audio-line-in-2layer-switch-node-keepaway [emi] (topology/verified, workspace)
  Two sources combine into one 2-layer-specific rule. The amp's own layout section calls the output/filter current loop an aggressor in EMI terms ("the size of this current loop determines its effectiveness as an antenna", SLOS708 10.1) and tells the designer to keep it small. Separately, a TI class-D layout note states the general coupling rule for any continuously-switching net: it "must not be routed in the adjacent layer with any other signal without ground shielding in between layers" (SLAA896 sec 2.4), illustrating a switching net with a ground-shield layer between it and a victim signal as the valid case (Fig 5) and the same two nets stacked with NO shield layer between them as invalid (Fig 6). A 2-layer board has no inner layer to put between the switch-node/filter copper and the line-in net - the ground-shield option in Fig 5 does not exist here, so the only tool left is physical distance on the shared routing layer (plus keeping the bottom-layer GND pour intact and unslotted under both regions, the same pour that provides the loop's own return path).
  rule: aggressor=class-D switch node / output copper / LC (or ferrite) filter - continuously switching, and per the amp's own layout section the output-to-filter loop is explicitly an antenna layer_rule=a switching net must not share a layer boundary with another signal unless a ground layer sits between them; on 2 layers no inner ground layer exists, so PHYSICAL SEPARATION on the shared layer is the only defense victim=the line-in net - high impedance (tens of kOhm) and unbuffered before the amp's input pin

- audio-line-in-analog-input-star-ground [return-path] (principle/verified, workspace)
  A low-level single-ended audio input's ground node(s) (the AC-grounded unused leg, any input-stage reference) must reference the amplifier's own quiet ground point by a dedicated trace, not the shared power-return pour. Concept (SLAA719 Fig 2): tying input-stage ground nodes to the PCB ground plane lets switching/output current develop real noise voltages across the plane between those nodes and the amp's analog ground. Measured (Fig 3/4, sec 2.1-2.2): a TPA3244 board wired this way matched at 1 kHz (Fig 3) but was "quite different" between channels at 100 Hz (Fig 4) - low frequency is where sustained current peaks are longest. A separate TPA3245 board, 100 Hz, was "even worse": CH1 0.013% vs CH2 0.0049% THD+N at 20 W (Fig 5) - that specific pair of numbers is the TPA3245 case, not TPA3244. Star-wiring those ground nodes to the analog ground reference (Fig 6) and retesting the TPA3244 board (Fig 7, sec 3.1) matched the channels and improved overall THD+N; the fix was not re-run on the TPA3245 board. PRINCIPLE: the mechanism (shared-plane IR noise couples asymmetrically into whichever ground node sits electrically closer to the noise source) applies to any low-level analog input on a board that also carries switching return current, independent of Zin, Cin, layer count, or part family; only the measured numbers above are per-part.
  rule: failure_signature=channel-to-channel THD+N mismatch that gets worse at LOW audio frequency and HIGH output power, not a broadband noise floor problem reference_point=the amplifier's own analog/quiet ground pin (or, on parts with one shared GND, the IC's GND pad/pins used as the datasheet's own 'star ground' point) routing=a dedicated trace per input ground node back to that reference point, not a tie-in to whatever the shared power-return pour is convenient at

- audio-line-in-cap-corner-vs-popup-settle [selection] (family/verified, workspace)
  The same Cin that sets the bass corner (f=1/(2*pi*Zin*Cin)) also sets, with Zin, the RC time constant the coupling caps charge through at power-up. SLOS708 sec 7.3.7 recommends keeping that RC <= 1 ms "if possible", tied explicitly to its own ~10 ms power-up window (DS elec-char turn-on time) - "if the input capacitors are not allowed to completely charge, there will be some additional sensitivity to component matching which can result in pop if the input components are not well matched." At Zin=60 kOhm/20 dB this board's 2.2 uF gives ~132 ms, well past both the 1 ms guideline and the 10 ms window - a deliberate bass-extension choice (vs. the datasheet's own 1.5 uF/1.8 Hz recommendation) that trades some margin against mismatch-driven pop for deeper bass. This is a real tradeoff to state explicitly at review, not an oversight: it raises sensitivity to the two coupling caps (signal leg + AC-grounded leg) being well matched in value, not just individually correct.
  rule: bass_corner=f_corner = 1/(2*pi*Zin*Cin) - larger Cin extends bass response failure_mode=an under-charged, mismatched-pair of coupling caps at SDZ/mute release is a pop, not just a slow bass roll-in popup_guideline=keep Zin*Cin (the input RC time constant) <= 1 ms if possible, so the coupling caps fully charge inside the device's ~10 ms power-up window

- audio-line-in-single-ended-unused-leg-ac-ground [diff-pair] (topology/verified, workspace)
  The amp's input stage is truly differential and cancels common-mode noise between its two input pins; a single-ended source only drives one of them. The datasheet's own single-ended recipe (SLOS708 sec 7.3.7) is: apply the source to either input, and AC-ground the OTHER input through a capacitor EQUAL IN VALUE to the signal-leg coupling cap - not a direct short to ground, which would create a large impedance mismatch between the two legs the differential stage compares. Best noise performance comes from AC- grounding at the audio source rather than at the device input pin (shorter return for the unused leg's own local noise). The two-cap arrangement (Astra's C1/C3 to INP, C2/C4 from INN to GND) matches this exactly. Mismatch between the two legs' impedance is not just a DC-offset issue - it degrades transient/pop performance, so a value/tolerance mismatch between the two caps reads as an audible symptom, not just a bench-meter one.
  rule: impedance_match=the impedance seen at both differential inputs should be the same for good transient (pop) performance signal_leg=source -> Ci -> INP (or INN), same coupling cap value/type as the other leg unused_leg=AC-ground the unused input through its OWN coupling cap of equal value, not a direct tie to ground and not left floating
  source: research/sources/tpa3116d2.pdf p.16 7.3.7 Differential Inputs

- class-d-amp-fault-latch-self-clear [sequencing] (family/verified, workspace)
  Thermal and short-circuit faults on the TPA31xxD2 latch. p18 (7.3.11): the die trips at 150 C +/-15 C, enters shutdown with outputs disabled, and stays there ('this is a latched fault'); the fault is reported on FAULTZ as a low. To recover without a microcontroller, 'connect the FAULTZ pin directly to the SDZ pin' - FAULTZ pulls SDZ low, which clears the latch, and the part restarts when the die cools. p18 Fig 31 gives the alternative for a uP: SDZ must be held low for more than 1.4 s to clear the latch. p4: FAULTZ is open drain (needs a pull-up), SDZ high = outputs enabled. p17 (7.3.8 Table 4): over-current (output short to PVCC or GND), over-temperature and DC offset are LATCHED with FAULTZ low; PVCC under/over-voltage are self-clearing. p17 (7.3.10): the short-circuit latch is cleared by cycling SDZ low, and the same FAULTZ-to-SDZ tie gives automatic recovery. p26 Fig 37 shows the tie: R13 100k pull-up on SDZ with FAULTZ wired to the same node. Design consequence for a copper-only 2-layer board: sustained overload past the thermal budget is survivable - the part cycles on thermal shutdown - but audible; the self-clearing tie is the right default when no host exists, and the latched form (FAULTZ to a host, SDZ from the host) when one does. The 10 ms input-cap charging window (p16 7.3.7, RC <= 1 ms) applies at every restart, so a self-clearing design must also keep the input RC small or it pops on each recovery.
  rule: sdz_low_clear_s=1.4 self_clear=FAULTZ tied to SDZ, one pull-up thermal_trip_c=150

- class-d-amp-output-loop-star-ground [power-loop, return-path] (principle/verified, workspace)
  Principle for any switching audio output stage: the loop from each output pin through its filter (ferrite or LC) and the small filter cap back to GND is the board's antenna, so its area sets the EMI; make it as small and tight as possible, and bring every ground - PVCC decoupling, filter caps, snubbers - to the IC's GND/thermal pad as a central (star) ground. SLOS708 p28 (10.1): 'keep the current loop from each of the outputs through the ferrite bead and the small filter cap and back to GND as small and tight as possible. The size of this current loop determines its effectiveness as an antenna'; 'all ground should be connected at the IC GND, which should be used as a central ground connection or star ground'; the filter should be placed as close to the output terminals/outputs as possible. p29 Fig 40 annotations: 'output filters placed close to the output pins to minimize return loop', 'direct low impedance traces for PVCC and output traces'. SLOU342A p7 Fig 4: L1-L4 sit one part-length from OUTxx pins on wide traces, the filter caps between the inductors and the terminals with their GND ends on the top pour; p9 Fig 6 x-ray: the bottom-side routes are the wide PVCC feed from the binding post to the two PVCC pin groups plus about nine short small-signal jumpers left of U1 - nothing bottom-side under the output loops on the right. - dc-input-bulk-esr-damping-budget [inrush, selection] (topology/verified, workspace)
  Applying the dc-input hot-plug principle here (10.8-13.2 V, 200 uF total bulk = 100 uF polymer + 100 uF electrolytic, no TVS, hotplug_ring_v_max 26 V vs vabs_max_v 30 V): 26 V is essentially SLUAAL8's undamped 2x-Vin estimate (2*13.2=26.4 V) - the op point already assumes NO damping, matching SSZTDA5's finding that real electrolytic ESR is usually below datasheet max, so treating the 200 uF bank as self-damping is optimistic. Margin to 30 V abs-max is only 1.15x, tighter than TI's own plotted cases (~1.5-1.6x Vi off a damped 0.15-0.21 ohm lead). Splitting 200 uF into low-ESR polymer (<=30 mOhm) plus higher-ESR electrolytic is the right shape - the polymer serves SLYT199's ripple/distortion duty (ESR sized low, then derated 30-50% below the ripple ceiling, eq 2-4), the electrolytic is meant to serve hot-plug damping - but the two duties pull ESR opposite ways, so only the electrolytic side may run higher. Given the tight 1.15x margin and SSZTDA5's caution that assumed electrolytic ESR underdelivers, do not accept the electrolytic's damping on datasheet-ESR faith alone: confirm it against R_lead+R_cap > 2*sqrt(L_lead/C_bulk) for the actual lead length, or add a small dedicated series-R snubber as the SLUAAL8 fallback when the cap side "cannot have a large series resistance". A snap-back TVS, if ever added, is never appropriate: it collapses below the rail and discharges the bulk bank back through it.

- dc-input-hotplug-ring-physics [inrush] (principle/verified, workspace)
  A bare dc-input (bench supply, adapter, or battery on wire leads, no upstream regulator, no attach-capacitance contract the way USB/PD/PoE give one) hands the board an unmanaged voltage step into whatever capacitance sits at the input. Lead R/L in series with that capacitance forms an under-damped RLC that a live connect excites. Zero series R reduces the step response to Vi*(1-cos wt), a 2x peak (SLUAAL8 sec 2, eq 1-3, Fig 2-1). More C damps the peak without removing it; more lead L raises the peak and lengthens the ring (Fig 2-2, 2-3); only series R suppresses it, per R_lead+R_cap > 2*sqrt(L_lead/C_in) (sec 3 eq 4). This is a PRINCIPLE, not a per-board bound: it applies to any board whose input capacitance is charged through an unmanaged lead, whether that capacitance feeds a regulator VIN pin or a load directly - only the numbers (peak vs abs-max, actual series R present) are per-board. Two traps: (1) counting on an electrolytic's ESR for damping - SSZTDA5 measured real ESR often well below the published max, worse at higher Vin; (2) an added series damping resistor must be surge-rated: SSZTDA5 measured ~2900 W peak in a 1 ohm resistor at 54 V hot-plug (Ppk=Vin_max^2/R) despite near-zero steady-state dissipation, destroying a general-purpose part of that rating on the bench. SLUAAL8's own fix is not the IC pin's own capacitance ("cannot have a large series resistance") but a small RC snubber (Fig 3-1: 2 ohm 0.5 W anti-surge + 2.2 uF near the supply pin).
  rule: binding_limit=hot-plug LC ring at the board input capacitance vs the board's abs-max voltage rating, not a source-declared capacitance budget damping_criterion=R_lead + R_cap > 2*sqrt(L_lead/C_in); more C damps the peak without removing it, more lead L raises the peak and lengthens ringing, only series R suppresses the ring damping_resistor_hazard=an explicit series damping resistor sees the full step energy in microseconds (Ppk = Vin_max^2 / R) and must be a surge-rated part, not a general-purpose one of the same nominal power esr_reality=do not assume a low-cost aluminium electrolytic's ESR provides the damping its published max implies - actual effective ESR is often well below the datasheet max, giving much less damping and much more ringing than assumed undamped_peak=zero series R reduces the model to Vi*(1-cos wt) - a 2x peak

- lc-output-filter-butterworth-pairing [selection] (topology/verified, workspace)
  Pick L and C from the single-ended equivalent, targeting Butterworth Q = 1/sqrt(2) at the DESIGN load. For a cap-to-ground (Type-2) BTL filter the SE circuit is L in series, C = C_g to ground, R_L = R_BTL/2 (Fig 1-14, p13); for a differential (Type-1) cap C = 2 x C_BTL (Fig 1-10, p11). Then L = R_L sqrt(2)/w0, C = 1/(w0 R_L sqrt(2)), Q = R_L sqrt(C/L), and the worked 4 ohm / 40 kHz example lands on 10 uH and 0.68 uF (p11, eq 7). TI's quick-selection tables (p18) list 10 uH + 0.68 uF at 61 kHz with 0.12 dB peaking at 20 kHz and -33 dB at 400 kHz / -40 dB at 600 kHz (Table 1-4, 6 ohm), 10 uH + 0.47 uF at 73 kHz for 8 ohm and 10 uH + 1.0 uF at 50 kHz for 4 ohm. Note Table 1-4's Q of 0.639 for 10 uH + 0.68 uF is what eq 7 gives for 15 uH, not 10 uH (eq 7 gives 0.78 at 6 ohm); trust the equation, not that cell. The TPA31xxD2 datasheet's own filter is 10 uH + 0.68 uF per leg to GND for 4-8 ohm (Fig 35, p23) and is the test condition behind its RL(BTL) minimum-load row (p5). Fig 1-6 (p7) is why the Q target matters: underdamped peaking is harsh and can trip overcurrent, overdamped rolls off audio. Attenuation at the carrier is the second selection check: read it off the table for the switching frequency actually programmed.

- lc-output-filter-cap-voltage-dc-bias [selection] (principle/verified, workspace)
  The filter cap of a single-supply class-D stage sits at PVDD/2 DC with the audio swing on top, and on the switching edges sees the pulse plus its overshoot (Fig on p32: DC, DC+AC, AC and pulse+overshoot panels); the rated voltage must cover all of it. Ceramics lose capacitance with DC bias: TI's guideline is C_derated = C_rated x (1 - V_applied/V_rated), i.e. "50 V on a 100 V part loses about 50 %", and the vendor's curve is the exact number (p32; Fig 1-41 p40, a generic ceramic curve naming no dielectric: the 50 V-rated part is down ~15 % at 50 V, the 25 V part ~12 % near 23 V). A capacitance drop moves f0 up and Q down, so the derated value is what goes into the pairing equation. X7R gives +/-15 % over -55..125 C (p40); ESR under 1 ohm keeps ripple-current loss low (p32). DISAGREEMENT on the voltage class: the app note says "> 150 V is mandatory, 250 V recommended" (p32) - written for TI's high-voltage PurePath HD stages - while the TPA31xxD2 family (PVDD max 26 V) is shipped by TI with 0.68 uF 50 V X7R 1206 filter caps (EVM BOM item 9, p9) and 100 V X7R 10 nF snubber caps (item 10). The family evidence is the higher tier for this block: 50 V at PVDD <= 26 V is TI's own practice; size the rating from the PVDD actually used, not from the app note's high-voltage rule.
  rule: cap_voltage_seen=DC = PVDD/2 plus the full audio swing plus edge overshoot ceramic_derating_guideline=C_derated = C_rated x (1 - V_applied / V_rated), then check the vendor DC-bias curve dielectric=X7R or better (+/-15 % over temperature); low ESR (< 1 ohm)

- lc-output-filter-dcr-dissipation [thermal] (topology/verified, workspace)
  DCR is a real dissipation line: P = I_out^2 x DCR (eq 14, p24), and "for a BTL amplifier ... there are two inductors in series with the load, so the DCR power loss for a single BTL channel is 2x the loss of just one inductor". Fig 1-27 (p24) shows the inductor DCR share rising to about 2.5 W of a 21 W system loss at 200 W total output on a TPA3251 (2 x BTL into 4 ohm, so 100 W per channel = 5 A rms, 7 A peak) - small in fraction, but it sits in the inductor body, not the heatsinked IC. At the 3 A / 66 mOhm point this is 0.59 W per inductor, 1.2 W per channel, 2.4 W for a stereo pair at full current, dissipated in four 7 mm bodies - a number the thermal budget must carry alongside the IC's. Idle loss is core loss, not DCR: it scales with the ripple current at fpwm, and inductors of identical inductance differed by more than 3x in idle PVDD power (Table 1-7, p23-24: 1.09 W vs 3.79 W), so a shielded ferrite part with a high parallel Rp at the switching frequency is worth more than a few mOhm of DCR. Derate Isat/Irms for the ambient the inductor will actually see: Coilcraft rates Irms at 20 C and 40 C rise separately (doc 1404, p1). Lower DCR also drops the load-current loss that makes the AD-modulation LC "required" in the first place (7.3.13, p21).
  rule: idle_loss=core loss at fpwm with the idle ripple current - compare inductors by Rp at the switching frequency p_dcr_per_channel=2 x I_out^2 x DCR (two inductors in series with a BTL load)

- lc-output-filter-ground-return-2layer [return-path] (topology/verified, workspace)
  The filter caps and snubbers return switching current, so where their GND goes is a return-path decision. The datasheet makes the IC GND the star: "All ground should be connected at the IC GND ... star ground" (10.1, p28), with PVCC decoupling and filter caps grounded there. The layout example gives the 2-layer form: top layer filled with GND, lots of vias top-to-bottom, no wires cutting the GND layer (Fig 40, p29); bottom layer a solid GND plane for the low-impedance return, vias along the board edge, and the one wide non-GND copper on it is the PVCC feed from the supply post to the IC (Fig 41, p30). The EVM matches: its bottom (Fig 4, p7) carries the wide PVCC route to both PVCC pin groups and otherwise short signal routes, while the output copper from the OUTxx pins through L1-L4 to the posts is all on top (Fig 3, p6), where the GND fill surrounds the filter and the caps' GND ends drop straight into it. Rule for a 2-layer board: keep the output path on the component layer, tie each filter cap's GND pad into the top fill and through nearby vias into the bottom pour, and let that pour run unbroken under the IC to its PowerPAD/GND pins; the PVCC route is the one allowed cut in the bottom copper and must not pass between the IC and the filter caps' vias. Bulk PVCC caps return to the same star (p28); on the EVM the PVCC post and bulk caps C7/C18 sit on the output side of U1 beside the filters, so the two loops share that side and are kept apart by the star, not by distance.
  rule: no_cuts=no traces cutting the GND under/around the IC planes=bottom layer solid GND for the return path, top layer filled with GND, stitched with many vias star=all grounds join at the IC GND (pad/pins) - the filter caps' return included

- lc-output-filter-inductor-isat-and-min-l [selection] (topology/verified, workspace)
  Three current checks on the filter inductor. (1) Peak current is the audio peak into the lowest load plus the switching ripple; at idle the ripple peak is PVDD/(8 L fpwm) (eq 12, p22, from Fig 1-25's triangle at 50 % duty), which is 0.38 A for 12 V / 10 uH / 400 kHz. (2) Isat is a vendor definition, not a ceiling: some vendors rate Isat at a 30 % inductance drop and "use of this inductor all the way to the Isat rating results in very poor audio performance" (1.4.1, Fig 1-20, p19). Coilcraft's class-D table (doc 1404, p1) prints Isat at 10 / 20 / 30 % drop side by side (e.g. UA8014 10 uH: 8.7 / 9.1 / 9.4 A), which is the form to compare against. Judge the part on its L-vs-I curve at the peak, not on the headline. THD at mid power tracks inductor linearity (Table 1-6, Fig 1-21/1-22, p19-20). (3) Minimum inductance at the overcurrent trip: with a shorted output the inductor sees the full PVDD and di/dt = PVDD/L until the OC protection responds (1.4.3, eq 13, p22-23); the TPA31xxD2 datasheet requires Lo >= 1 uH "under short-circuit condition" (6.3, p5) and trips at 7.5 A for TPA3116D2/TPA3118D2, 4.5 A for TPA3130D2 (6.6, p7). So the inductor's curve must still show >= 1 uH at 7.5 A; a 10 uH part rated 5.5 A Isat passes only if its curve, not its rating, says so. TI's own EVM uses a 10 uH 5.8 A part (Toko 931BS-100M, BOM item 20, p9).

- lc-output-filter-placement-and-loop [emi] (topology/verified, workspace)
  The switching edges are fast, so the current loop from each output pin through the inductor and the filter cap back to GND is the radiator: "the size of this current loop determines its effectiveness as an antenna" (10.1, p28). Place the LC close to the outputs and ground its caps; a ferrite-bead EMI filter, if used instead of or after the LC, goes as close to the output terminals as possible (p28). The datasheet's layout example (Fig 40, p29) annotates exactly this: "Output filters placed close to the output pins to minimize return loop" and "Direct low impedance traces for PVCC and output traces", with the top layer filled with GND. The EVM (Fig 3, p6) shows the arrangement on a 2-layer board: the four inductors L1-L4 sit immediately to the right of the IC's OUTxx pins in a 2 x 2 block, the 0.68 uF caps C21-C24 sit at the inductor outputs on the way to the binding posts, the RC snubber parts are between the pins and the inductors, and every output trace is short, wide and on the top layer. The bottom (Fig 4, p7) carries no output copper: its one wide route is the PVCC feed from the supply post to the IC, so the output loop never changes layer. The switch-node snubber (if fitted) has its own tighter rule: "layout of the snubber network is tight and returns directly to the GND pins on the IC" (7.3.14, p21). Speaker wires are antennas above 30 MHz (p21), so the filter is the last thing before the connector, not the first thing after the IC.
  rule: loop=output pin -> L -> filter cap -> GND kept as small and tight as possible; its area is the antenna placement=LC filter close to the output pins; ferrite/EMI filter close to the output terminals traces=direct, wide, low-impedance output traces, no detours

- lc-output-filter-q-tracks-load [selection] (topology/verified, workspace)
  A fixed L/C is critically damped at one load only. Q = R_L sqrt(C/L) (eq 7, p11) rises linearly with R_L, so the check is at the highest impedance the board must drive, and the 20 kHz peaking must stay small there. For 10 uH + 0.68 uF to ground (C = 0.68 uF in the SE circuit), eq 7 gives Q = 0.52 at 4 ohm (R_L 2 ohm), 0.78 at 6 ohm and 1.04 at 8 ohm; f0 stays at 61 kHz, so the 8 ohm response peaks about +1.5 dB near 45 kHz (the second-order peak for Q 1.04), above the audio band, and the 4 ohm case is slightly overdamped, which is why TI lists the pair for 4-8 ohm (Fig 35, p23). Fig 1-11 (p12) shows the same trend for the Type-1 cousin (C_BTL 0.68 uF, i.e. SE C 1.36 uF, Q 1.47 at 8 ohm): 2 ohm rolls off early, 8 ohm peaks about +4 dB near 40 kHz; Fig 1-18 (p17) shows it again for the hybrid filter. The post-filter 3.3 ohm + 10 nF branch is NOT audio-band damping: its corner is 1/(2 pi 3.3 10n) = 4.8 MHz and at 61 kHz the 10 nF alone is about 260 ohm against an 8 ohm load. TI's Fig 37 (p26) labels it EMI C-RC SNUBBER and pairs it with a 1 nF cap per leg; the EVM populates it as R15-R18 3.3 ohm with C25-C28 0.01 uF/100 V X7R (p9). Damping across the load range therefore comes from the L/C pair itself; if a design must be flatter at 8 ohm, retune C (10 uH + 0.47 uF, Table 1-3) rather than lean on the RC.
  rule: post_filter_rc_corner_mhz=4.8 post_filter_rc_is_damping=False q_10uh_680nf_4ohm=0.52 q_10uh_680nf_8ohm=1.04 q_scaling=Q is proportional to R_L at fixed L/C - check Q at the HIGHEST load impedance
